# Excelコンボ（お試し版）

Excel のブックの中に、AI との対話窓を組み込んだ VBA ツールです。
マクロ入りブック（.xlsm）1つで完結していて、ダウンロードして開けばすぐ試せます。

## できること

- 対話窓（AI作業窓）から、開いているシートに日本語で注文できます
  例：「担当ごとの数量合計を出して」「空白行を削除して」「見出しを太字にして罫線を引いて」
- 調べるだけでなく、書き込みもできます（値の書き込み・書式・行と列の操作・条件付き書式）。
  AI が書いた結果を読み戻して自分で確かめる往復ループつき
- AI の書き込みは［元に戻す］で巻き戻せます
- よく使う注文は「定型」に、複数手順の作業は「手順書」に登録して増やせます
- 練習台のテスト用シート1〜5つき。何度書き換えても「シートを元に戻す」で原本に戻ります

## 使えるAI

| エンジン | 必要なもの |
|---|---|
| Gemini（API直結） | Gemini APIキー（Google AI Studio で無料発行できます）を目次シートの黄色い欄に貼る |
| Claude | claude CLI（Claude Code）にログイン済みなら、キーなしでそのまま動きます |

## 動かすまで

1. `お試し版 Excelコンボ.xlsm` をダウンロードして開く（マクロを有効にする）
2. Excel のオプション → トラスト センター → マクロの設定 で
   「VBA プロジェクト オブジェクト モデルへのアクセスを信頼する」を ON にする
3. 目次シートのキー欄に Gemini APIキーを貼る（Claude を使う場合は不要）
4. 目次シートのボタンから対話窓を開いて、テスト用シートに聞いてみる

## 注意

- APIキーは自分のものを使ってください（利用料は自分のキーに掛かります）
- 貼ったキーはこのブックの目次シートに保存されます。ブックを人に渡すときは、キー欄を消してから渡してください
- AI の書き込みは、実行前に内容の確認が入るのが既定です
